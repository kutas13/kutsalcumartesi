# Kutsal Cumartesi Kasa

Next.js tabanlı özel finans paneli.

## Geliştirme

```bash
npm install
npm run dev
```

Ardından `http://localhost:3000` adresini açın.

## Vercel

Bu depo Vercel'de Next.js olarak doğrudan yayınlanabilir.
